# 轻量级后台管理面板 用户操作手册

## 1. 面板定位

轻量级后台管理面板面向系统管理员和运营人员,提供三大核心功能:

- **用户管理增强** - 用户列表、角色管理、禁用/启用、登录历史追踪
- **内容管理系统(CMS)** - 公告管理、帮助文档、通知消息
- **系统设置** - 基础设置、主题配置、邮件SMTP、安全策略、自动备份

## 2. 账号与登录

### 2.1 管理员账号
管理员通过OAuth登录系统,系统所有者自动获得管理员权限。管理员拥有所有功能的访问权限,包括用户管理、内容管理和系统设置。

### 2.2 经销商账号
经销商账号由管理员在系统中创建,初始密码由管理员设置。经销商首次登录时必须修改密码,以确保账号安全。

## 3. 界面结构

轻量级后台管理面板采用统一的布局结构:

- **顶部导航栏** - 显示当前登录用户、快速搜索、通知入口、退出按钮
- **左侧菜单** - 包含用户与权限、内容管理(CMS)、系统设置、审计与日志(如启用)等模块入口
- **主内容区** - 显示列表、详情或表单内容
- **右上角操作区** - 常见操作按钮(新建、导出、刷新等)

## 4. 用户与权限管理

### 4.1 用户列表管理

用户列表提供快速管理用户账号的能力,包括启用/禁用、重置密码、分配角色等操作。

**操作步骤:**

1. 进入「用户管理」→「用户列表」页面
2. 使用搜索功能查找用户(支持用户名、手机号、邮箱、经销商编号搜索)
3. 点击用户行进入详情页面,查看基础信息、账号状态、角色分配、最近登录记录

**管理建议:**

- 对高风险账号启用更强的安全策略(强密码要求、登录IP限制)
- 定期清理长期未登录的账号,建议禁用而非删除以保留审计记录
- 离职人员账号应立即禁用并记录操作原因

### 4.2 角色管理

角色管理基于RBAC(基于角色的访问控制)模型,通过角色控制菜单和接口权限。

**操作步骤:**

1. 进入「用户管理」→「角色管理」页面
2. 点击「新建角色」按钮
3. 填写角色名称(如:财务、运营、客服、只读审计等)
4. 勾选权限范围:
   - **数据权限** - 可访问的数据范围(经销商、订单、结算、政策等)
   - **操作权限** - 可执行的操作(新增、编辑、删除、审批、导出等)
5. 保存后返回用户详情页面分配角色

**权限设计建议:**

- 遵循最小权限原则,只授予必要的权限
- 财务角色应拥有结算审批权限但不应有政策修改权限
- 客服角色应有查看权限但限制删除和导出权限
- 定期审查角色权限配置,及时调整不合理的权限设置

### 4.3 禁用/启用用户

当需要临时冻结用户账号时(如离职、异常行为、临时冻结),可以使用禁用功能。

**操作步骤:**

- 在用户列表中找到目标用户
- 点击操作列的「禁用」按钮
- 确认禁用原因(系统会记录到审计日志)
- 需要恢复时,同样位置点击「启用」按钮

**注意事项:**

- 禁用用户会立即终止其所有会话
- 禁用操作会记录到审计日志,包括操作者、时间、原因
- 建议在禁用前通知相关人员,避免影响正常业务

### 4.4 登录历史追踪

登录历史功能用于定位异常登录、排查账号共享等安全问题。

**操作步骤:**

1. 进入用户详情页面
2. 点击「登录历史」标签页
3. 查看登录记录:登录时间、IP地址、设备/浏览器信息、登录结果(成功/失败)

**异常处置:**

- **异常IP登录** - 禁用账号 + 强制修改密码 + 检查权限变更记录
- **多地同时登录** - 调查是否存在账号共享,必要时强制下线
- **频繁登录失败** - 可能是暴力破解,启用账号锁定策略

## 5. 内容管理(CMS)

### 5.1 公告管理

公告管理用于发布系统通知、结算规则变更、维护通知等重要信息。

**操作步骤:**

1. 进入「CMS」→「公告管理」页面
2. 点击「新建公告」按钮
3. 填写公告信息:
   - **标题** - 简洁明确的公告标题
   - **内容** - 详细的公告内容(支持富文本格式)
   - **可见范围** - 选择后台或门户(或两者)
   - **生效时间** - 设置公告的开始和结束时间
4. 点击「发布」按钮
5. 发布后可在列表中进行置顶或撤回操作

**最佳实践:**

- 重要公告应设置置顶,确保用户第一时间看到
- 公告内容应简洁明了,避免冗长的描述
- 临时维护通知应及时撤回,避免过期信息干扰

### 5.2 帮助文档

帮助文档用于形成标准化操作说明,特别适合经销商门户侧的常见问题解答。

**操作步骤:**

1. 进入「CMS」→「帮助文档」页面
2. 先创建文档分类(如:对账说明、采购计算器使用、密码管理等)
3. 在分类下新建文章:
   - **标题** - 清晰的问题或主题
   - **正文** - 详细的操作步骤或说明
   - **关键词** - 便于搜索的关键词
   - **排序** - 控制文档在分类中的显示顺序
4. 发布后在前台验证可见性

**内容建议:**

- 使用图文结合的方式,提高可读性
- 每篇文档聚焦一个主题,避免内容过于分散
- 定期更新文档,确保内容与系统功能保持一致

### 5.3 通知消息

通知消息用于系统事件的主动触达,如结算单待审批、对账单生成等。

**操作步骤:**

1. 进入「CMS」→「通知消息」页面
2. 点击「新建通知」按钮
3. 选择通知对象:
   - 按角色(如:所有财务人员)
   - 按经销商(如:特定经销商)
   - 单个用户
4. 填写通知标题和内容
5. 点击「发送」并查看送达状态

**使用场景:**

- 结算单审批提醒
- 政策参数变更通知
- 系统维护预告
- 重要功能上线通知

## 6. 系统设置

### 6.1 基础设置

基础设置包含系统的基本配置信息,如系统名称、LOGO、时区、数据导出开关等。

**操作步骤:**

1. 进入「系统设置」→「基础设置」页面
2. 修改相应配置项
3. 点击「保存设置」按钮

**常用配置:**

- **系统名称** - 显示在页面标题和登录页面
- **系统LOGO** - 上传或设置LOGO图片URL
- **时区设置** - 影响时间显示和日志记录
- **数据导出开关** - 控制是否允许用户导出数据

### 6.2 主题配置

主题配置用于统一后台和门户的视觉风格,包括颜色方案和暗色模式支持。

**操作步骤:**

1. 进入「系统设置」→「主题配置」页面
2. 选择预设主题或自定义颜色
3. 预览效果
4. 保存配置

**主题选项:**

- 主色调选择
- 暗色/亮色模式切换
- 字体大小调整
- 圆角风格设置

### 6.3 邮件SMTP配置

邮件SMTP配置用于系统发送通知邮件、找回密码、系统告警等功能。

**操作步骤:**

1. 进入「系统设置」→「邮件SMTP」页面
2. 填写SMTP服务器信息:
   - **主机地址** - SMTP服务器地址
   - **端口** - 通常为25、465或587
   - **用户名** - SMTP账号
   - **密码** - SMTP密码
   - **加密方式** - SSL/TLS
3. 点击「发送测试邮件」验证配置
4. 测试成功后保存配置

**常见SMTP服务商:**

- 腾讯企业邮箱:smtp.exmail.qq.com:465(SSL)
- 阿里云邮件推送:smtpdm.aliyun.com:465(SSL)
- Gmail:smtp.gmail.com:587(TLS)

### 6.4 安全策略

安全策略用于降低撞库和内部滥用风险,保护系统安全。

**推荐配置项:**

- **密码强度** - 设置最小长度和复杂度要求(大小写+数字+特殊字符)
- **登录失败锁定** - 设置失败次数和锁定时间窗口
- **会话有效期** - 管理员会话应设置更短的有效期
- **IP白名单** - 财务和管理员可选启用IP限制

**操作步骤:**

1. 进入「系统设置」→「安全策略」页面
2. 根据安全需求配置各项策略
3. 保存配置后立即生效

### 6.5 自动备份

自动备份功能确保数据可恢复,降低数据丢失风险。

**操作步骤:**

1. 进入「系统设置」→「自动备份」页面
2. 配置备份策略:
   - **备份频率** - 每日、每周或自定义
   - **保留周期** - 备份文件保留天数
   - **备份目标** - 本地磁盘或对象存储(推荐)
3. 点击「立即执行备份」测试配置
4. 验证备份文件可恢复后保存配置

**备份建议:**

- 生产环境建议每日备份
- 备份文件应存储到独立的存储服务(如腾讯云COS)
- 定期进行恢复演练,确保备份可用
- 重要操作前手动执行一次备份

## 7. 审计与日志

审计日志记录系统中的关键操作,确保可追溯性和合规性。

**必须审计的操作:**

- 政策参数修改
- 订单增删改
- 结算计算与审批
- 用户权限变更
- 系统设置修改

**查看审计日志:**

1. 进入「审计与日志」→「操作日志」页面
2. 使用筛选条件:
   - 时间范围
   - 操作者
   - 操作对象
   - 操作类型
3. 查看详细日志信息
4. 导出日志用于合规审查

## 8. 常见问题与处置

### 8.1 无法登录
**可能原因:**
- 账号被禁用或锁定
- 密码错误次数过多触发锁定
- 网络问题或服务器故障

**处置步骤:**
1. 检查账号状态(禁用/锁定)
2. 管理员重置密码
3. 查看登录历史,分析失败原因
4. 如是系统问题,检查服务器日志

### 8.2 权限不足
**可能原因:**
- 角色权限配置不正确
- 数据范围限制
- 会话过期

**处置步骤:**
1. 确认用户的角色分配
2. 检查角色的权限配置
3. 重新分配正确的角色
4. 用户重新登录使权限生效

### 8.3 公告不显示
**可能原因:**
- 可见范围设置错误
- 生效时间未到或已过期
- 公告未发布

**处置步骤:**
1. 检查公告的可见范围设置
2. 确认生效时间配置
3. 确认公告状态为"已发布"
4. 清除浏览器缓存后重试

### 8.4 邮件发送失败
**可能原因:**
- SMTP配置错误
- 服务器出站端口被封
- SMTP账号密码错误
- 邮件服务商限流

**处置步骤:**
1. 检查SMTP配置信息
2. 测试服务器出站端口连通性
3. 验证SMTP账号密码
4. 查看邮件服务商的发送限制
5. 重新测试邮件发送

### 8.5 备份失败
**可能原因:**
- 磁盘空间不足
- 对象存储权限不足
- 数据库连接失败
- 备份任务超时

**处置步骤:**
1. 检查磁盘空间或对象存储配额
2. 验证对象存储的访问权限
3. 检查数据库连接状态
4. 查看备份任务日志,定位具体错误
5. 调整备份策略或增加资源

## 9. 最佳实践

### 9.1 用户管理
- 定期审查用户账号,清理不活跃账号
- 离职人员账号应立即禁用
- 高权限账号应启用更强的安全策略
- 避免共享账号,每人独立账号

### 9.2 内容管理
- 公告内容应简洁明了,避免冗长
- 帮助文档应及时更新,与系统保持一致
- 通知消息应有明确的行动指引
- 定期清理过期内容

### 9.3 系统设置
- 重要配置修改前应先备份
- 安全策略应根据实际情况调整
- 定期检查备份任务执行情况
- 邮件配置应定期测试

### 9.4 安全合规
- 定期审查审计日志
- 关键操作应记录详细信息
- 敏感数据访问应有审批流程
- 定期进行安全培训
